# 差分隐私保证说明

本应用采用**有明确数学保证的拉普拉斯机制（Laplace Mechanism）**发布统计，
而不是“加一点噪声”或“隐藏小单元”式的经验做法。以下口径与代码
（`fedread/dp.py`、`fedread/engine.py`）一一对应。

## 1. 单位邻接（adjacency）

邻接数据集定义为：加入或移除**一个完整保护单位**。保护单位由研究计划事前
声明：

* `unit = person`：一个人的全部观测（可能跨多家机构、多条记录）一起变化；
* `unit = household`：一个家庭的全部观测一起变化。

因此统计单位是保护单位，**绝不是记录行数**。同一人参加三家机构的活动、
同一家庭有多名成员，在邻接意义下都只算作一个单位的变化。

## 2. 每单位贡献上限与数值界限

发布前在 SQL 层做两步确定性处理：

1. **贡献截断**：按 `(单元, 保护单位)` 分区，以
   `(机构, 观测日, 记录编号)` 确定性排序，每单位只保留前
   `contribution_limit` 条记录。跨机构同单位的记录在同一排序流中竞争，
   保证移除一个邻接单位带走的记录数不超过该上限。
2. **数值裁剪**：数值型指标的每条保留记录裁剪到计划声明的 `[lower, upper]`。

由此得到每条发布向量的 **L1 敏感度上界**：

| 发布量 | L1 敏感度 Δ |
| --- | --- |
| 单位计数 / 0-1 指示和 | `contribution_limit` |
| 裁剪数值和 | `contribution_limit × max(|lower|, |upper|)` |

## 3. 机制与组合

* 对每个加噪量独立采样 `Lap(Δ / ε_cell)`，单量满足 **(ε_cell, 0)-DP**
  （纯差分隐私，δ = 0）。
* 均值/比例类指标联合发布两个量（计数 + 和/指示和），ε 在两者间对半分配，
  再做后处理（相除、裁剪到合法区间）。后处理不增加隐私消耗。
* **顺序组合（sequential composition）**：同一研究计划下全部已成立披露
  保守地线性累加 ε 与 δ；分组各单元也计入同一计划预算，不存在
  “每家机构授权 = 一份免费额度、可以任意相加”。
* 计划声明的 δ 仅作簿记上限；本机制实际 δ 恒为 0，组合后仍为 0。

## 4. 确定性噪声：重试不能挑答案

噪声由 `SHA-256(计划密钥 ‖ 发布指纹 ‖ 单元标签 ‖ 量标签)` 派生均匀样本，
再经拉普拉斯逆 CDF 变换得到：

* 相同请求（同计划、同资料版本、同指标/人群/分组形状）重试，噪声**逐位相同**，
  研究员无法通过重复申请挑选有利结果；
* 不同单元、不同量、不同计划使用域分隔标签，不会复用同一抽样；
* 完全相同且针对同一资料版本的已发布结果直接**复用**，零新增 ε/δ 消耗；
* 指标、人群、分组、资料版本或用途任一变化都会改变发布指纹，
  按新披露重新判定授权依赖与额度消耗。

## 5. 精度限制

拉普拉斯噪声尺度 `b = Δ / ε_cell`，95% 边际误差为
`ln(20) · b ≈ 2.996 · Δ / ε`。研究员在**预览**阶段即可看到：

* 声明单元结构（来自计划白名单，不枚举数据，因此不泄露单元存在性）；
* 每个量的敏感度、尺度与 95% 边际误差；
* 组合后的累计 ε/δ 与剩余额度；
* 不可行时的可调整条件（下调 ε、减少分组、改申请可复用形状、
  等待授权恢复或更换版本）。

预览只基于计划声明参数推导，**不读取受限数据的真实统计**。

## 6. 事务性保证：送达与扣账同生共死

发布在单条 `BEGIN IMMEDIATE` 写事务内完成
「查额度 → 复用判定 → 授权依赖校验 → 聚合加噪 → 写 release →
写 ledger → 更新请求状态」。SQLite 写事务串行化：

* 两个并行请求即使各自余额看似够用，合起来超额时只有先提交者成功，
  后者标记 `budget_denied` 且**不扣任何额度**；
* 提交前崩溃：事务整体回滚，无发布、无扣账，可安全重试；
* 提交后崩溃/应答丢失：release 与 ledger 已同时持久，恢复例程按持久事实
  把请求收敛为 `published`，不重复扣账、不重抽噪声；
* 不存在“结果已送达但额度仍可被别人花掉”的中间态。
  使用者通过 `result` 查询发布是否成立，而不是凭进程显示猜测。

## 7. 授权撤回的边界

* 撤回按 `(计划, 资料版本)` 的**真实依赖**生效：仅停止该计划该版本下
  待审与已批未发的请求；联合统计依赖所有参与机构，缺任一家即停止，
  不能用其余机构替代发布。
* 已发布统计无法收回，其 ε/δ 消耗**不因删文件或撤回而退还**；
  旧结果仍可查询当时的授权范围、资料指纹与机制限制。
* 撤回一个机构不株连其他研究计划的任何结果。

## 8. 明确不提供的保证

* 本应用不做成员推断防护之外的“小单元抑制”——抑制本身不构成 DP 保证；
  空单元不展示仅为避免单元存在性推断，单元结构来自白名单。
* 拉普拉斯机制不使用高斯/亚采样放大等高级组合，组合核算是保守的线性上界。
* 全部数据为本地合成资料，应用不连接任何真实机构账户。
