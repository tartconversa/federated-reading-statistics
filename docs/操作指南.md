# 本地角色操作指南

纯标准库本地应用，无网络、无真实账户。全部数据为合成资料。

## 角色与合成操作者

| 操作者 | 角色 | 可操作计划 | 职责 |
| --- | --- | --- | --- |
| U1 | researcher 研究员 | PLAN1 | 预览、提交请求、查询获准结果 |
| U5 | researcher 研究员 | PLAN2 | 同上 |
| U2 | reviewer 审核人 | PLAN1/PLAN2 | 批准/驳回、执行发布 |
| U3 | institution 资料方 | PLAN1/PLAN2 | 撤回/恢复机构用途授权 |
| U6 | institution 资料方 | PLAN2 | 同上（PLAN2 专用演练身份） |
| U4 | administrator 管理员 | PLAN1/PLAN2 | 额度核对、披露审计、中断恢复、故障演练 |

## 初始化

```sh
python3 -m fedread.cli init --materials materials
# 库默认写入 state/fedread.db，可用 --db 或环境变量 FEDREAD_DB 更换
python3 -m fedread.cli catalog --actor U4
```

## 研究员：预览 → 提交 → 查询

```sh
# 预览只返回声明结构、敏感度、95% 边际误差、额度位置与调整建议，无真实统计
python3 -m fedread.cli preview --actor U5 --plan PLAN2 --metric count \
    --group-by '["region"]' --filters '{}' --version 2026-04-v1 --epsilon 0.4

# 提交（提出日须落在计划期限窗口内）
python3 -m fedread.cli submit --actor U5 --id Q-1 --plan PLAN2 --metric count \
    --group-by '["region"]' --filters '{"region":"urban"}' \
    --version 2026-04-v1 --epsilon 0.4 --delta 0 --as-of 2026-05-15

# 查询办理状态与已成立发布；未发布时明确告知状态，不返回任何数值
python3 -m fedread.cli list --actor U5 --plan PLAN2
python3 -m fedread.cli result --actor U5 --id Q-1
```

研究员接口不存在 records 导出；错误信息只含请求层面的原因，
不含人员/家庭/观测编号或原始值。

## 审核人：审核与发布

```sh
python3 -m fedread.cli review --actor U2 --id Q-1 --decision approve
# 批准不等于发布；发布才在单事务内扣账并加噪
python3 -m fedread.cli publish --actor U2 --id Q-1
```

驳回用 `--decision reject`。发布若遇共享额度竞争，请求进入 `budget_denied`，
不扣额度，研究员可按预览提示下调 ε 或改申请可复用形状后重新提交。

## 资料方：管理授权范围

```sh
# 撤回 I2 对 PLAN2/v1 的用途授权：待审与已批未发请求按真实依赖停止
python3 -m fedread.cli withdraw --actor U6 --grant G5 --reason "用途终止"
# 演练恢复（已停止的请求不会自动复活，需重新提交）
python3 -m fedread.cli reinstate --actor U6 --grant G5
```

已发布结果不受撤回影响、额度不退还；其他计划不受株连。

## 管理员：核对、审计与恢复

```sh
python3 -m fedread.cli budget --actor U4 --plan PLAN2          # 共享额度账
python3 -m fedread.cli disclosures --actor U4                  # 披露↔授权/版本/贡献/额度核对
python3 -m fedread.cli audit --actor U4 --plan PLAN2           # 只追加审计记录
python3 -m fedread.cli recover --actor U4                      # 中断续办
```

### 故障演练（可选）

```sh
# 提交前崩溃：事务回滚，重试即可，无扣账
python3 -m fedread.cli arm-crash --actor U4 --point before_commit
# 提交后、应答前崩溃：release/ledger 已持久，recover 收敛状态
python3 -m fedread.cli arm-crash --actor U4 --point after_publish
```

## 请求状态机

```
draft ──approve──▶ approved ──publish──▶ published（终态，可被同形请求复用）
  │                   │
  ├─reject──▶ rejected（终态）      ├─额度竞争失败──▶ budget_denied（可改条件后重办）
  └─撤回依赖──▶ stopped（终态）     └─授权撤回──▶ stopped（终态）
```
